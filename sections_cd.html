Ordered Curriculum with Milestones

Four stages, sequenced by dependency — not popularity. Each stage has objectives, topics, and measurable completion criteria.

🗺️
How to use this curriculum: Complete each stage before advancing. The stages are dependency-ordered: factor models require statistics, statistics requires calculus and probability, a backtester requires Python. Resist the urge to skip ahead.
Stage 1 — Foundation Weeks 1–8 · ~120 hrs

Objective: Build the mathematical and programming substrate. By the end you will manipulate financial data, implement basic statistical tests, and write clean testable Python.

Mathematics Track

  • Calculus: limits, derivatives, chain rule, partial derivatives, integration, Taylor series. Needed for MLE, Black-Scholes, gradient descent.
  • Linear Algebra: vectors, matrix ops, inverse, eigenvalues, positive semi-definiteness, SVD. Needed for covariance, PCA, regression.
  • Probability: sample spaces, random variables, PMF/PDF/CDF, expectation, variance, key distributions (Normal, Lognormal, t, Binomial).
  • Exercises: Prove variance-of-sum formula. Derive OLS estimator with calculus. Compute eigendecomposition of 3×3 covariance matrix by hand.

Programming Track

  • Python Core: data structures, OOP, file I/O, list comprehensions, generators, error handling.
  • NumPy: ndarray, broadcasting, vectorized ops, linalg module.
  • pandas: Series/DataFrame, time-indexing, merge, groupby, resample, missing data.
  • Git: commit, branch, merge, pull request, .gitignore.
  • Project: Download SPY prices via yfinance. Compute log-returns. Plot cumulative return and rolling 30-day volatility. Commit to GitHub.

Stage 2 — Quantitative Methods Weeks 9–20 · ~200 hrs

Objective: Master core quant tools: statistical inference, time series, portfolio math, and derivatives intro. Build your first real projects.

Statistics & Econometrics

  • Inference: MLE, hypothesis tests (t, F, χ²), p-values and misuse, multiple testing correction (Bonferroni, BH).
  • Regression: OLS, Gauss-Markov, heteroskedasticity, HAC standard errors (Newey-West), ridge, LASSO.
  • Time Series: stationarity, ACF/PACF, ARIMA, unit root tests (ADF/KPSS), ARCH effects, GARCH(1,1), cointegration (Engle-Granger, Johansen).

Portfolio Theory & Finance

  • Return Math: arithmetic vs log returns, compounding, Sharpe, Sortino, max drawdown, Calmar.
  • Markowitz Optimization: efficient frontier, min-variance and tangency portfolios, constraints, numerical solution with cvxpy.
  • CAPM & Factor Models: beta, alpha, Fama-French 3-factor and 5-factor models, time-series regression.
  • Derivatives Intro: option payoffs, put-call parity, binomial tree, Black-Scholes formula, Greeks, implied volatility.

Stage 3 — Advanced Research Methods Weeks 21–36 · ~280 hrs

Objective: Professional-level research: rigorous backtesting, ML for finance, market microstructure, execution costs, and complete research workflows. Build 3+ portfolio-quality projects.

Backtesting & Strategy Research

  • Backtesting Engine: event-driven architecture, portfolio accounting, transaction costs, slippage, position sizing, risk limits, performance attribution.
  • Bias Elimination: survivorship bias correction, look-ahead bias prevention, data snooping, walk-forward validation, regime analysis.
  • Strategy Classes: cross-sectional momentum, time-series momentum, mean reversion, pairs trading, factor investing. Each must be tested rigorously.

ML for Finance

  • Features: technical indicators, fundamental ratios, volatility features — all with strict look-ahead controls.
  • Models: gradient boosting (XGBoost, LightGBM), random forests, ridge/LASSO. Understand when each fails.
  • Validation: purged k-fold CV, embargo periods (Lopez de Prado 2018). Standard CV is wrong for time series — know why.
  • Signals: Information coefficient (IC), IC Information Ratio (ICIR), transfer coefficient.

Stage 4 — Specialization Weeks 37–52 · ~300 hrs

Objective: Deep expertise in your target quant path. Build 3–5 publication-quality projects. Prepare for technical interviews.

QR Track

  • Alternative data signal construction
  • High-dim factor models (PCA, sparse factors)
  • Hierarchical Risk Parity
  • Regime-switching models (HMM)
  • Deep learning for sequences (with extreme validation rigor)
  • Research report writing to professional standards

QT Track

  • Order book dynamics and LOB analysis
  • Optimal execution (TWAP, VWAP, Almgren-Chriss)
  • Market making (Avellaneda-Stoikov model)
  • High-frequency data cleaning and analysis
  • Latency and slippage modeling
  • Real-time systems design concepts

FE Track

  • Stochastic calculus (Ito integral, Girsanov, martingales)
  • Risk-neutral pricing framework
  • Local vol (Dupire) and stochastic vol (Heston)
  • Finite difference PDE methods (Crank-Nicolson)
  • Interest rate models (Vasicek, CIR, HJM)
  • Model calibration to market data

📚 Core Textbooks

Title & Author(s)LevelTopicsCostWhy Essential
Options, Futures, and Other Derivatives
John C. Hull (11th ed., 2022)		 Intermediate Derivatives pricing, Greeks, Black-Scholes, interest rate models ~$60–180; older eds fine Standard derivatives textbook across universities and banks globally. Every derivatives quant has read this.
Stochastic Calculus for Finance I & II
Steven Shreve (2004)		 Advanced Discrete/continuous-time, Ito calculus, risk-neutral pricing, rigorous Black-Scholes ~$40–80 per volume Gold standard for rigorous mathematical treatment. Required on FE path.
Active Portfolio Management
Grinold & Kahn (2nd ed., 1999)		 Intermediate Information ratio, Fundamental Law of Active Management, factor models, portfolio construction ~$60–100 The intellectual foundation of quantitative equity investing. IR = IC × √BR is cited in virtually every quant research meeting.
Advances in Financial Machine Learning
Marcos Lopez de Prado (2018)		 Intermediate–Advanced ML for finance, purged CV, labeling, feature importance, backtesting biases ~$50–80 Most practically useful modern book for quant researchers applying ML. Purged cross-validation is now standard practice.
The Econometrics of Financial Markets
Campbell, Lo & MacKinlay (1997)		 Advanced Return predictability, factor models, market microstructure, derivative pricing, term structure ~$80–120 Academic reference for financial econometrics. Chapter 2 on returns is required reading for any serious quant.
Quantitative Risk Management
McNeil, Frey & Embrechts (2nd ed., 2015)		 Intermediate–Advanced VaR, CVaR, copulas, extreme value theory, credit risk ~$60–90 Authoritative risk measurement text. Introduces copulas and EVT which go well beyond VaR limitations.
Analysis of Financial Time Series
Ruey S. Tsay (3rd ed., 2010)		 Intermediate ARIMA, GARCH, multivariate time series, high-frequency data, nonlinear models ~$50–80 Practical and thorough treatment of financial time series. Best GARCH coverage in any textbook.
Machine Learning for Asset Managers
Marcos Lopez de Prado (2020)		 Intermediate Hierarchical Risk Parity, denoising covariance matrices, feature selection, entropy features ~$40–60 Compact, practical companion to AFML. Denoising and detoning of correlation matrices is particularly valuable.
Python for Finance
Yves Hilpisch (2nd ed., 2019)		 Beginner–Intermediate Python for finance, NumPy/pandas, derivatives pricing, algorithmic trading intro ~$50–80 / O'Reilly subscription Bridges Python and finance concepts. Good first project book before diving into pure quant material.
A First Course in Probability
Sheldon Ross (10th ed., 2019)		 Beginner–Intermediate Probability fundamentals, distributions, expectation, conditioning, CLT ~$50–90 Standard probability textbook. Foundation for every statistical method in quant finance. Interview questions draw heavily from this material.
